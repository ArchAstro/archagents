# Security Triage Agent Sample

Top-level deployable agent. Install to provision a fresh agent in your org wired up with the routines and tools below. This is the sample bundle's deployable AgentTemplate — copy and tailor as needed.

## Setup

- **`SECURITY_TEAM_EMAIL`** — Where to send weekly triage summaries. Leave blank to disable
- **Install `enablement/slack_bot`** — Add the ArchAstro Slack bot to your workspace and the channel
